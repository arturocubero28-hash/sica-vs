# Imágenes a presentar en la página de inicio (landing)

Poné acá tus capturas reales del sistema y aparecerán en la landing,
reemplazando los mockups dibujados por código.

## Nombres exactos que busca la landing

- `dashboard.png` → el mockup grande del hero (Panel de control del admin)
- `guardia.png`   → tarjeta "El guardia valida en segundos"
- `arqueo.png`    → tarjeta "La caja cuadra sola"

## Cómo funciona

Si el archivo existe, la landing muestra tu captura. Si no existe, muestra
el mockup dibujado por código (así nunca se ve una imagen rota).

## Recomendaciones

- PNG, ancho 1200–1600 px.
- Tomá la captura en pantalla ancha (no en celular).
- Sin la barra de direcciones del navegador, solo el contenido.
