# Fotos de la infraestructura (galería de la landing)

Poné acá las fotos reales de la residencial para la sección
"Seguridad que se ve y se siente".

## Nombres (sin importar la extensión)

La galería acepta cualquier extensión de imagen común: .png, .jpg, .jpeg, .jfif, .webp, .avif, .gif o .bmp.
Solo importa que el nombre (antes del punto) sea exactamente uno de estos:

- tranca-vehicular  -> Acceso vehicular (la barrera / tranca)
- caseta-guardia    -> Caseta de vigilancia
- camaras-hd        -> Cámaras de seguridad
- acceso-peatonal   -> Acceso peatonal

Ejemplos válidos: tranca-vehicular.jpg, tranca-vehicular.jfif,
caseta-guardia.jpeg, camaras-hd.png ... todas funcionan.

## Cómo funciona

Si la foto existe (en cualquiera de esas extensiones), la galería la
muestra con el efecto hover-zoom. Si no existe, muestra un marcador con
degradado e ícono (nunca una imagen rota).

## Ojo con Windows

Si renombrás y el archivo queda como "tranca-vehicular.jpg.txt", es
porque Windows tenía la extensión oculta. Activá "Extensiones de nombre
de archivo" en la pestaña Ver del explorador para ver el nombre real y
corregirlo.

## Recomendaciones

- Horizontal (apaisado), idealmente 1200 px de ancho o más.
- Relación de aspecto cercana a 16:10 (se recorta a eso).
