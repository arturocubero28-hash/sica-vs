# Fotos de la infraestructura (galería de la landing)

Poné acá las fotos reales de la residencial para la sección
"Seguridad que se ve y se siente".

## Nombres exactos que busca la galería

- `tranca-vehicular.jpg` → Acceso vehicular (la barrera / tranca)
- `caseta-guardia.jpg`   → Caseta de vigilancia
- `camaras-hd.jpg`       → Cámaras de seguridad
- `acceso-peatonal.jpg`  → Acceso peatonal (torniquete / portón)

## Cómo funciona

Si la foto existe, la galería la muestra con el efecto hover-zoom. Si no
existe todavía, muestra un marcador con degradado y un ícono (nunca una
imagen rota), para que la landing se vea bien aunque falten fotos.

## Recomendaciones

- Formato JPG, horizontal (apaisado), idealmente 1200 px de ancho o más.
- Relación de aspecto cercana a 16:10 (se recorta a eso).
- Buena iluminación; fotos de día se ven mejor.
