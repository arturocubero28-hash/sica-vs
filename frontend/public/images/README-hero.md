# Foto de fondo del hero (opcional)

Si querés una foto real de fondo en el hero (la entrada de la residencial),
guardala en esta misma carpeta (public/images/) con este nombre:

- hero-residencial   (con extensión .jpg, .jpeg, .png o .webp)

Ej: hero-residencial.jpg

## Cómo funciona

- Si la foto existe, el hero la usa de fondo, nítida, con un velo oscuro
  encima para que el texto blanco se lea perfecto.
- Si NO existe, el hero muestra una "aurora" animada de luces (CSS), que
  también se ve muy bien y no necesita ningún archivo.

## La foto ideal

- La entrada principal: que se vea la tranca/barrera, la caseta, el portón.
- De atardecer o noche con luces encendidas queda más espectacular.
- Mínimo 1920x1080, horizontal, nítida.
- No hace falta que sea oscura: el velo encima se encarga de oscurecerla
  lo justo para que el texto se lea.
